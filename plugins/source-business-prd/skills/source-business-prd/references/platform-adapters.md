# 宿主与工具适配

宿主按能力适配，不设产品白名单。共享 Skill 不依赖固定的 MCP 前缀、专有子代理、聊天记忆或插件根目录变量。首先查看宿主可用工具，再将能力映射到实际工具；脚本路径以本次已加载的 SKILL.md 所在目录为根，复制单个 Skill 目录即包含所有执行资源。

## 任意新宿主的接入协议

1. **加载指令与资源**：宿主原生支持 Agent Skills 时，使用其实际注册/发现机制；没有注册机制但能够读取外部指令和文件时，显式读取 `SKILL.md`，再按需读取 references。安装目录、工具前缀及命令通过宿主实际能力确定，不从其他产品类推。
2. **建立能力映射**：记录下表中可用的本地工具、连接器或 API；工具名称可不同，保留相同的证据语义与产物契约。没有能力的项明确降级，不用宿主名称决定是否可执行。
3. **执行与交付**：按业务场景分析，使用宿主允许的文件或产物接口交付 Markdown 和 JSON；无法落盘时明确交付形式和恢复限制，不能声称已写入本地目录。无法获取必要来源或快照字段时，保留草稿和待补项。
4. **记录实际验证**：保存宿主及版本、加载方式、能力映射、实际调用与产物检查结果；用相同受控案例核对。新增宿主通常只需补充接入说明，核心业务方法和证据契约保持共用。

| 能力 | 要求与降级 |
| --- | --- |
| 指令与来源读取 | 执行源码分析的基础；不能访问来源时先取得可读取材料，不生成实现事实 |
| 搜索与语义分析 | 可用宿主搜索、语言服务、连接器或局部读取；符号/调用链工具是增强，缺失时披露调查盲区 |
| 产物写出与恢复 | 使用宿主允许的文件或产物接口，保留稳定 ID；不能持久化时明确恢复限制 |
| 哈希及快照获取 | 使用实际可用的文件、哈希或执行工具；缺失的取证字段留待补齐，不伪造完整检查点 |
| Python 执行 | 可用时运行附带校验器；不可用时人工核对契约，保留命令并标注脚本校验未执行 |
| 数据库只读访问 | 可选；使用已授权的等价工具，无连接时继续静态分析 |
| 图表渲染 | 可选；无渲染器时保留图源和等价文字，说明未渲染 |

这些要求描述执行范围，不保证每个宿主都能完成全部步骤。完整分析需满足实际取证和交付要求；兼容指令格式与已通过端到端验证分别记录。

## 代码探索

遵守目标仓库规则。有 `.codegraph/` 且规则要求时先调用 CodeGraph explore；无索引时不自动创建。索引过期、返回截断或语言/框架无法解析时读取对应的当前文件核对，注明盲区。

Serena 可用时先遵守其 initial_instructions / 项目激活要求，按符号概览、定义/实现、引用与配置建立调用路径。工具名按宿主实际发现。每个证据保存当前仓库、路径、符号与行号；多项目工具共享会话不并发切换。无语义工具时用宿主的文件搜索和局部源码读取，补看注册/路由/依赖注入配置，披露动态派发覆盖限制。

## 数据库与图表

dbhub 或等价工具仅作为可选读取源；遵守 [multi-repo-and-db.md](multi-repo-and-db.md)。不在插件内安装或启动 MCP、不写入连接凭据。已有工具缺能力时说明并降级，不创建隐含外部 AI 调用。

Markdown 与 Mermaid 为基本交付格式；宿主支持其他图表技能时按需使用。脚本不依赖这些技能，也不负责图表渲染。大系统按场景分批保存状态，在任何宿主恢复均从输出 JSON 与文档继续。

## 已有宿主的分发示例和手动验证

以下是部分宿主的加载路径示例，不是穷尽列表，也不是本插件已完成端到端测试的声明。其他宿主采用上面的通用接入协议；使用示例时仍需对照实际版本和发现列表确认。

| 宿主 | 分发路径 | 验证 |
| --- | --- | --- |
| Codex | 当前市场条目与 `.codex-plugin/plugin.json`；Skill 在 `skills/source-business-prd/` | 安装后在新会话确认 Skill 发现，再运行受控案例 |
| Claude Code | `.claude-plugin/plugin.json` 与默认 `skills/` | `claude plugin validate <plugin-root>`；可用 `claude --plugin-dir <plugin-root>` 在本地会话加载；之后确认发现与试分析 |
| Antigravity | 将完整 Skill 目录放在项目 `.agents/skills/source-business-prd/`；全局目录按所用 App/CLI/IDE 文档确认 | 在宿主技能列表确认加载，再使用相同案例检查产物 |

Claude 可直接复制完整 Skill 到项目 `.claude/skills/source-business-prd/`；这不需要其他平台的清单。Antigravity 官方资料还列出全局 `~/.gemini/config/skills/`，不同产品表面及旧版路径有差异，应以当前宿主为准。安装和配置变更需有用户授权；生成插件不隐含安装。
