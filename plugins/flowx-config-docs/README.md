# FlowX Config Docs

这是一个独立的 Codex 插件，用于通过当前会话已配置的 dbhub MCP 查询 FlowX 数据字典、菜单权限和国际化配置，并按固定模板生成 Markdown 文档。

## 使用方式

输入目标数据库或 dbhub 数据源标识，以及配置业务范围：

```text
数据库：oms_test
配置需求：预约单相关的数据字典、菜单权限、国际化
```

插件每次固定输出三类配置表，并自动补齐英文、日文、韩文、西班牙语和葡萄牙语。无需选择语言。

输出文件写入当前工作区，命名为：

```text
flowx-config-{数据库名}-{日期}.md
```

## 查询和匹配

- dbhub 只执行只读的目标库确认、Schema 探索和配置查询。
- 插件不假设固定的 dbhub 工具名或 FlowX 表名，会先发现当前会话实际可用能力。
- 表名、字段名或业务范围无法唯一匹配时，列出候选和匹配依据，等待确认。
- Schema 和候选表已确认、条件查询成功但没有匹配数据时，仍输出完整的三类空模板，并注明“未查询到匹配配置”。
- 没有候选表、候选不唯一或 dbhub 不可用时，分别标记为无法识别、待确认或查询受阻，不伪装成空结果。

## 安全边界

插件不执行 INSERT、UPDATE、DELETE 或清理动作，不保存或输出 Token、Cookie、密码、连接串、完整 SQL 参数和完整原始响应。数据库已有翻译优先，缺失翻译只处理自然语言字段，并保留 key、编码、路由、权限标识和占位符。

本地 `scripts/` 只处理脱敏后的 JSON 和 Markdown 文件，不连接 dbhub 或外部翻译服务。
