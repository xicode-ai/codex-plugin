# FlowX 多语言翻译规则

## 固定语言

每次固定输出以下语言列，不提供语言选择：

| 列 | 语言 |
|---|---|
| `en` | 英文 |
| `ja` | 日文 |
| `ko` | 韩文 |
| `es` | 西班牙语 |
| `pt` | 葡萄牙语 |

## 优先级

1. 数据库已有非空翻译直接保留；
2. 只有自然语言字段为空时才自动翻译；
3. 未知语言代码或无法判断源文本时不猜测，记录翻译待人工确认。

不得翻译 key、编码、字典 key/value、路由、排序、授权标识、授权资源或操作类型代码。

## 占位符保护

翻译前提取以下形式的占位符：

```text
{unit}
${name}
{{count}}
:id
```

翻译后必须得到完全相同的占位符集合。例如：

```text
中文：待上架{unit}
英文：Pending Putaway {unit}
```

英文不能变成 `Pending Putaway`，也不能把 `{unit}` 翻译成普通文本。占位符集合不一致时，目标列标记为待人工确认，不静默采用结果。

## 格式保护

保留 Markdown、HTML、换行和转义结构。只翻译自然语言片段；代码、路径、变量、HTML 属性和 Markdown 链接目标不翻译。自动翻译数量和待确认数量写入文档的翻译说明区域，不改变三张固定表的列结构。
